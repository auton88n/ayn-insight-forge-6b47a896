# AYN AI Platform
AI collaborators: read CLAUDE.md first. It is the system map index.

AYN AI is a perceptive artificial intelligence that learns your habits, understands your goals, and helps you succeed.

## Technology Stack

- **Frontend**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS + shadcn/ui
- **3D Graphics**: Three.js + React Three Fiber
- **Backend**: Supabase (Auth, Database, Edge Functions, Storage)
- **AI Integration**: Multi-model LLM orchestration
- **Testing**: Vitest + Playwright E2E

## Features

- 🤖 Personal AI Assistant with emotional intelligence
- 🏗️ Engineering calculators (Beam, Column, Slab, Foundation, Retaining Wall)
- 🅿️ AI-powered parking lot designer
- 📊 Admin dashboard with analytics
- 🎫 Support ticketing system
- 🌍 Multi-language support (English, Arabic, French)

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Run tests
npm test

# Build for production
npm run build
```

## Environment Variables

Create a `.env` file with required Supabase credentials.
